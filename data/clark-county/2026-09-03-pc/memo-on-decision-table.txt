Subject:        Decision table for comprehensive plan periodic update deliberations



The decision table has been updated to help facilitate your deliberation on the comprehensive
plan update. The table has been structured in four sections: Map Amendments, Comprehensive
Plan Chapters and Appendices, Code Amendments, and Impact Fees. The table retains the
original numbering for all map amendments to provide continuity with the previous version of the
table. What has been added is a line item for each chapter in the Comprehensive Plan, a line item
for each Title 40 code section that is being proposed for amendment, and a line item for each of
the proposed impact fees. (The table also reﬂects that the Planning Commission has already
made a recommendation on the School and Fire impact fees, and no additional action is
required.)
The four sections allow you to select a section for deliberation and voting. The individual line items
within each section provides the opportunity to go through each item individually, or to select
certain items for additional consideration and make motions in batches for the rest.

      •   Map Amendments (1-29)
      •   Comprehensive Plan Chapters and Appendices (30-61)
      •   Code Amendments (62-91)
      •   Impact Fees (92-101)
The Planning Commission can start with any section outlined above to begin deliberations.
