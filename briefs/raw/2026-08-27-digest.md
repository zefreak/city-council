# Agenda digest — 2026-08-27 — RUN FAILED, NO DATA GATHERED

`python3 data/agenda_watch.py` could not reach either source. **No agendas were retrieved, so no
brief was written for this run.** This file exists so the gap in the record has a reason attached
to it.

## What happened

Every outbound HTTPS request from this run goes through the session's agent proxy, and the proxy's
egress policy refused the CONNECT for all three hosts the watch depends on:

| Host | Result |
|---|---|
| `vancouverwa.api.civicclerk.com:443` | 403 to CONNECT — policy denial |
| `clark.wa.gov:443` | 403 to CONNECT — policy denial |
| `vancouverwa.portal.civicclerk.com:443` | 403 to CONNECT — policy denial |

Recorded by the proxy itself at `$HTTPS_PROXY/__agentproxy/status` under `recentRelayFailures`,
timestamps 2026-08-27T01:13Z. The script's own traceback is
`urllib.error.URLError: <urlopen error Tunnel connection failed: 403 Forbidden>` raised from
`van_meetings()` on the first `Events` request.

The sanctioned fetch tool returns the same thing explicitly:
`{"error_type":"EGRESS_BLOCKED","domain":"clark.wa.gov"}`.

This is an allowlist question, not a bug in `agenda_watch.py` and not an outage at either council.
The proxy README is explicit that policy denials are to be reported rather than routed around, so
no workaround was attempted.

## What this means for the record

- `data/.agenda-watch-state.json` is **unchanged** — the script died before writing state, so
  nothing was marked seen. Whenever the hosts become reachable, a plain `python3
  data/agenda_watch.py` will pick up everything published since 26 August with no `--all` needed.
- Nothing is known about agendas published between 26 August and today. In particular:
  - **Clark County Tuesday 1 September** would be a regular meeting under the ~1st-and-3rd
    pattern, with its agenda due by 5pm Wednesday 26 August (Rules §VII.A). Whether it exists and
    what is on it is **unverified** — the listing could not be read.
  - **Clark County Council Time, Wednesday 2 September** — same, unverified.
  - **Vancouver Planning Commission, 8 September** — the agenda was already published on 21 August
    and is briefed at `briefs/2026-09-08-vancouver-planning-commission.md`. The **packet** was
    unpublished as of the 26 August run and could not be re-checked today. That packet is the
    thing to grab first on the next working run: the draft Title 20 text, the HB 1491 exclusion
    map and the impact fee schedule are all in it.
  - **Vancouver City Council, 14 September** — agenda expected around Wednesday 9 September.

## Fix

The two hosts need to be on the egress allowlist for the environment this routine runs in:

```
vancouverwa.api.civicclerk.com
clark.wa.gov
```

`vancouverwa.portal.civicclerk.com` is only needed for human browsing, not for the script.
Attachment blob fetches redirect to CivicClerk storage, so whatever host the `blobUri` points at
will need to be reachable too — that will only become visible once the API host itself is allowed.
