## Why this is worth the reading time

The recurring council items are exactly what the analysis is about, and it already contains the
counter-arguments and the corrections:

- **The Affordable Housing Fund** — §7 sizes it against the gap it is meant to close. An AHF
  administrative plan revision is not a routine item.
- **The property tax lid** — §8. Vancouver *cannot* raise the money from property tax; this is a
  legal constraint, not a political choice. Do not brief a proposal as if that option were open.
- **Capacity versus production** — §3. Zoned capacity is not the binding constraint and never has
  been, so an upzone briefed as a supply fix deserves scrutiny.
- **§4 is the strongest evidence *for* the plan**, deliberately given its own section. Read it
  before writing anything critical, so the brief argues against the best version of the case.
- **Filtering runs backwards** on the measured half of the stock (Part III) — and §11 is the
  number nobody quotes.
- **§24 is a correction to an earlier version of this analysis.** It is the model for how a wrong
  finding gets retracted here: name the error, fix the root cause, keep the record.

## Standing warning

The single largest error in the parent project came from missing what a source *did not* claim —
data that covered only owner-occupied properties, stated on page 11. Read what a document excludes
before citing what it shows.
